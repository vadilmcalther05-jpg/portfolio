# Mc Alther G. Vadil — Portfolio

This is a static portfolio site published with GitHub Pages.

- `index.html` is the main portfolio.
- `Digital-Profile.html` is the extended student profile page.
- Keep the profile image and any future certificate images in this repository so the pages can load them.

## Updating the portfolio

Edit the HTML files to update text, contact information, projects, or certificates. Add new images to the repository, then reference them with a relative path (for example, `images/certificate.jpg`). Commit the changes to the `main` branch; GitHub Pages will publish the update automatically.
