# Mc Alther G. Vadil — Portfolio

This static portfolio is published with GitHub Pages.

- `index.html` is the main portfolio.
- `Digital-Profile.html` is the extended student profile page.
- `portfolio-*.jpg` files are the permanent profile and project images used by the main portfolio.

To update the portfolio, edit the HTML files and commit the changes to the `main` branch. Add new permanent images to the repository and reference them with relative paths in the HTML.
